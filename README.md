[![Stars](https://img.shields.io/github/stars/Akbar-Lab-Droid/kursus-semua-bahasa-pemrograman?style=social)](https://github.com/Akbar-Lab-Droid/kursus-semua-bahasa-pemrograman)

**Satu repo untuk belajar semua bahasa pemrograman — dari nol sampai siap kerja.**

Tidak perlu bingung mau belajar bahasa apa dulu. Repo ini mengumpulkan **jalur belajar lengkap (full course)** untuk 18 bahasa pemrograman: untuk apa bahasa itu dipakai, seberapa sulit, kursus gratisnya di mana, proyek latihannya apa, dan kariernya ke mana. Semua berbahasa Indonesia, semua tautan gratis. Setiap bahasa dilengkapi contoh kode nyata yang bisa langsung dijalankan di folder [`examples/`](examples/).

> Cocok untuk: mahasiswa semua jurusan yang mau bisa coding, pemula yang baru mulai, dan siapa pun yang mau pindah bahasa atau menambah bahasa baru.

## Cara Pakai Repo Ini

1. **Baca Modul Dasar dulu** — cara kerja komputer, cara belajar coding, Git, dan algoritma. Ini berlaku untuk semua bahasa.
2. **Pilih 1 bahasa pertama** dari peta jalan di bawah. Jangan belajar 3 bahasa sekaligus di awal.
3. **Ikuti jalurnya tahap demi tahap** — dasar → menengah → proyek. Satu kursus gratis per tahap sudah cukup.
4. **Buat proyek di tiap tahap** — coding yang tidak dipraktikkan akan hilang. Setiap bahasa punya daftar proyek latihan.
5. **Baru tambah bahasa kedua** setelah bahasa pertama sudah bisa dipakai buat 1 proyek nyata.

## Bahasa Apa Dulu? (Peta Jalan)

| Tujuanmu | Mulai dari |
| --- | --- |
| Belum pernah coding sama sekali | **Python** — paling mudah dibaca, paling banyak tutorial |
| Mau bikin website | **HTML & CSS** → **JavaScript** → **TypeScript** |
| Mau bikin aplikasi Android | **Kotlin** (atau Java) |
| Mau bikin aplikasi iOS | **Swift** |
| Mau kerja data / AI | **Python** → **SQL** → **R** |
| Mau kerja game | **C#** (Unity) atau **C++** (Unreal) |
| Mau kerja sistem / backend cepat | **Go** atau **Rust** |
| Mau kuliah Informatika | **C** → **Java** → **Python** (urutan kampus kebanyakan) |
| Mau freelance website cepat | **PHP** + JavaScript |

Aturan praktis: **bahasa pertama terserah, yang penting selesai 1 proyek.** Bahasa kedua dan seterusnya akan jauh lebih mudah — konsepnya 80% sama, cuma sintaks yang beda.

## Modul Dasar — Sebelum Pilih Bahasa

### Cara Kerja Komputer (1 minggu)

- **CS50 Harvard** — pengantar ilmu komputer terbaik di dunia, gratis: https://cs50.harvard.edu
- **Khan Academy Computing** — dasar komputer & internet: https://www.khanacademy.org/computing

### Cara Belajar Coding yang Benar

- **Jangan cuma nonton tutorial** — ketik sendiri setiap baris kode, ubah-ubah, rusak, perbaiki.
- **Aturan 20 menit** — kalau mentok lebih dari 20 menit, cari di Google/Stack Overflow, jangan diam.
- **Belajar How to Learn** — kursus gratis soal cara belajar: https://www.coursera.org/learn/learning-how-to-learn
- **Catat error-mu** — error yang sama tidak boleh menghabiskan waktumu dua kali.

### Git & GitHub (wajib semua bahasa)

- **GitHub Skills** — belajar Git interaktif gratis: https://skills.github.com
- **Pro Git Book** — buku gratis: https://git-scm.com/book/en/v2
- Perintah wajib: `clone`, `add`, `commit`, `push`, `pull`, `branch`, `merge`.

### Algoritma & Struktur Data (wajib semua bahasa)

- **Khan Academy Algorithms** — pengantar algoritma: https://www.khanacademy.org/computing/computer-science/algorithms
- **freeCodeCamp** — kurikulum algoritma & struktur data: https://www.freecodecamp.org/learn/
- Topik wajib: array, string, linked list, stack, queue, hash map, sorting, searching, Big-O.

## Jalur Per Bahasa

Setiap bahasa berisi: untuk apa, tingkat kesulitan, jalur belajar, kursus gratis, proyek latihan, dan karier.

### Python

**Untuk apa:** data, AI/machine learning, web backend, otomatisasi, scripting.
**Kesulitan:** ⭐ Mudah — bahasa pertama terbaik untuk pemula.

**Jalur belajar:**
1. Dasar: variabel, tipe data, if/else, loop, fungsi, list & dictionary
2. Menengah: OOP, file & error handling, modul & package, virtual environment
3. Lanjut: framework (Django/Flask/FastAPI), pandas & NumPy, machine learning

**Kursus gratis:**
- MIT 6.0001 — pengantar Python: https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/
- Kaggle Learn — Python & machine learning, langsung praktik: https://www.kaggle.com/learn
- freeCodeCamp — Scientific Computing with Python: https://www.freecodecamp.org/learn/scientific-computing-with-python/
- Dokumentasi resmi Python: https://docs.python.org/3/tutorial/

**Proyek latihan:** kalkulator, bot Telegram sederhana, analisis dataset CSV, website Flask, prediksi harga rumah (machine learning).

**Contoh kode:** [`examples/python/`](examples/python/) — `hello.py` + `kalkulator.py`

**Karier:** data analyst, AI engineer, backend developer, data scientist.

### JavaScript

**Kesulitan:** ⭐⭐ Sedang — wajib kalau mau bikin website.

**Jalur belajar:**
1. Dasar: variabel, tipe data, fungsi, DOM, event
2. Menengah: ES6+ (arrow function, promise, async/await), fetch API, modul
3. Lanjut: framework (React/Vue), Node.js + Express, TypeScript

**Kursus gratis:**

- JavaScript.info — tutorial modern, gratis: https://javascript.info
- Web Programming UNPAS (YouTube) — berbahasa Indonesia: https://www.youtube.com/@sandhikagalih

**Proyek latihan:** to-do list, kalkulator, game tebak angka, website portofolio, REST API sederhana.

**Contoh kode:** [`examples/javascript/`](examples/javascript/) — `hello.js` + `fizzbuzz.js`

## FAQ

**Berapa bahasa yang harus dikuasai?**
Satu dulu sampai bisa bikin proyek nyata. Setelah itu, bahasa kedua butuh waktu 30–50% dari bahasa pertama. Programmer senior biasanya menguasai 3–5 bahasa, tapi mendalam di 1–2.

**Bahasa apa yang paling banyak lowongan di Indonesia?**
JavaScript, PHP, Java, dan Python — dalam urutan itu, untuk web dan backend. Untuk data/AI: Python dan SQL.

**Apakah harus kuliah Informatika untuk jadi programmer?**
Tidak. Mayoritas skill di repo ini bisa dipelajari otodidak lewat kursus gratis di atas. Ijazah membantu di awal, portofolio yang menentukan.

**Saya mentok di satu materi, bagaimana?**
Normal. Cari di Stack Overflow (https://stackoverflow.com), tanya di forum freeCodeCamp atau Discord komunitas, dan istirahat dulu — sering solusinya muncul setelah jeda.

**Berapa lama sampai bisa kerja?**
Dengan 2–3 jam latihan per hari: 6–12 bulan sampai bisa magang/junior, tergantung bahasa dan konsistensi. Portofolio 3 proyek nyata lebih meyakinkan daripada 10 sertifikat.
