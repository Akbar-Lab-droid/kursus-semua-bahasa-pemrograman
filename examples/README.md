# Contoh Kode — Kursus Semua Bahasa Pemrograman

Setiap bahasa punya **2 contoh kode nyata** yang bisa langsung dijalankan. Mulai dari `hello` (program pertama), lalu satu contoh praktis (kalkulator / FizzBuzz / analisis).

| Bahasa | File | Cara menjalankan |
| --- | --- | --- |
| Python | `python/hello.py`, `python/kalkulator.py` | `python3 python/hello.py` |
| JavaScript | `javascript/hello.js`, `javascript/fizzbuzz.js` | `node javascript/hello.js` |
| TypeScript | `typescript/hello.ts`, `typescript/kalkulator.ts` | `npx tsc` lalu `node` hasil compile, atau Node 22+ langsung |
| HTML & CSS | `html-css/hello.html`, `html-css/style.css` | Buka `hello.html` di browser |
| SQL | `sql/hello.sql`, `sql/analisis.sql` | Jalankan di SQLite / MySQL / PostgreSQL |
| Java | `java/HelloWorld.java`, `java/Kalkulator.java` | `javac HelloWorld.java && java HelloWorld` |
| C | `c/hello.c`, `c/kalkulator.c` | `gcc hello.c -o hello && ./hello` |
| C++ | `cpp/hello.cpp`, `cpp/fizzbuzz.cpp` | `g++ hello.cpp -o hello && ./hello` |
| C# | `csharp/Hello.cs`, `csharp/Kalkulator.cs` | `dotnet run` (buat project dulu) |
| Go | `go/hello.go`, `go/fizzbuzz.go` | `go run hello.go` |
| Rust | `rust/hello.rs`, `rust/fizzbuzz.rs` | `rustc hello.rs && ./hello` |
| PHP | `php/hello.php`, `php/kalkulator.php` | `php hello.php` |
| Ruby | `ruby/hello.rb`, `ruby/fizzbuzz.rb` | `ruby hello.rb` |
| Swift | `swift/hello.swift`, `swift/fizzbuzz.swift` | `swift hello.swift` |
| Kotlin | `kotlin/Hello.kt`, `kotlin/FizzBuzz.kt` | `kotlinc Hello.kt -include-runtime -d hello.jar && java -jar hello.jar` |
| Dart | `dart/hello.dart`, `dart/fizzbuzz.dart` | `dart hello.dart` |
| R | `r/hello.R`, `r/analisis.R` | `Rscript hello.R` |
| Shell/Bash | `shell/hello.sh`, `shell/backup.sh` | `bash shell/hello.sh` |

Semua contoh ditulis dengan komentar berbahasa Indonesia dan sudah dicek kebenarannya.
